# Links: LinkPularConteudo, LinkDeTexto e LinkDeVoltar

- **Status:** proposta
- **Componente:** `src/app/components/ui/links.tsx` (o mesmo arquivo e a mesma API do DS FindLook)
- **Data:** 2026-11-27
- **Branch:** `claude/consistencia-final`
- **Documentação:** Molduras e estados › Links de texto e pular para o conteúdo

## Motivo
O DS FindLook tinha o link "Pular para o conteúdo"; o Dani Moscatelli não, e a migração do site pediu o mesmo componente.

## API
`LinkPularConteudo` (`href`, padrão `#conteudo`; o `<main>` precisa do id e de `tabIndex={-1}`), `LinkDeTexto` (`externo`, `forte`, `comoLink`), `LinkDeVoltar` (`comoLink`).

## Acessibilidade
O link de pular só aparece com o foco do teclado, 44 px de altura, foco visível; link externo avisa "abre em nova aba".

## Testes
`pnpm build`, página Molduras no navegador (390 e 1280 px), axe sem falhas.
